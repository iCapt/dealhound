DealHound — a real Black Friday deal finder: 235 verified deals from 7 stores (Walmart, Target, Best Buy, Sephora, LEGO, Nike, Amazon), every price read on the store's own page on 27 Nov 2026 and linked back to the product. Search, filter by category, store and discount size, sort by discount or saving, and see a "really a deal" verdict for every deal, computed from the store's own sale price against its usual price. Static site, zero network at runtime, works on desktop and phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
